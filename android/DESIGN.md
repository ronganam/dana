# Dana Design System v3 — "Circuit"

The phone's redesign (Nov 2026; build spec and phases: `docs/redesign-circuit.md`). Night violet, dark first, tonal groups without borders, and one structural motif: a line with nodes. Sections below that still describe "Ink & Paper" screens are being rebuilt phase by phase; the tokens and components here are current.

## Tokens (`ui/theme/`)
- **Palette** (`Color.kt`): dark canvas `#14101C`, surface `#1C1726`, surface high `#241E30`, surface highest `#2E2740`; ink `#F2EEF8`, ink soft `#B9B0C9`, mute `#8C849C`. Light theme = the same roles on lavender paper (canvas `#F7F4FC`, ink `#1C1726`, accent `#5F45C2`). The app opens **dark** (`ThemeSettings` defaults to Dark; Light and System stay in Settings). ONE accent, violet (`#B9A5FF` dark): Dana, live things, actions, selection. Filled buttons: a static horizontal gradient `#C9B8FF` → `#DDB6F4` (violet leaning to plum; light `#5F45C2` → `#7A3DB4`, white text) with dark text (`accentFill()` = `circuitColors.accentFilled` → `accentFilledEnd`, mirrored in RTL, flat and dimmed when disabled); `InkButton` SOLID, `ActionPill` solid, the ask bar's talk pill, a card's `FilledAction` and the approval card's yes use it. **Warm** (`#FFB27A`, `Hue.EMBER`, `circuitColors.warm`) only for "needs you" and late, never decoration; a "needs you" group sits on `circuitColors.warmSurface`. Green (`Hue.SAGE`) only where something must read as done. Never hardcode colours in screens — use `MaterialTheme.colorScheme.*`, `circuitColors` or `hues`.
- **Material mapping**: primary = accent, primaryContainer = tonal accent, secondaryContainer = the nav pill / tonal header buttons (`circuitColors.indicator`), background/surface = canvas, surfaceContainerLow/Container = surface (groups, nav), High = surface high (inner rooms, inputs), Highest = surface highest, outlineVariant = hairlines and idle wires.
- **Circuit roles** (`CircuitColors`, `circuitColors`): accent, accentFilled/onAccentFilled, accentTonal, indicator/onIndicator, warm/warmSurface/warmSurfaceHigh, wire/wireRaised/wireDim, node/nodeDim (idle and paused node strokes), ink/inkSoft/mute.
- **Hero surface**: `heroBrush(base)` (`components/Delight.kt`) — a card's static fill with a soft violet wash at its top (base lerped 32% towards `accentTonal`), faded into the base by 60% of its height so nodes punched out on the base lower down still match. Only on a hero card (Now's calm card); the canvas stays plain.
- **Hues** (`Hue`, names shared with the web app and the watch): EMBER needs you (warm) · AMBER reminders, tasks, warnings · SAGE done, calls, money in · TEAL messages, notifications · SKY calendar, info · PLUM people, memory · ROSE alerts, errors, money out — tuned for the violet night so only EMBER reads orange. Read them through `hues` (`hues.of(Hue.SKY)`, `hues.tint(c)`, `hues.text(c)`, `hues.forName(name)`, `hues.fromHex(stored)`). A picked hue is stored as `Hue.storedHex` (the value the web and watch know it by); `fromHex` maps stored and older values back to the theme's value. Hues carry meaning in the chrome too, softly: the current place's nav pill is its hue's tint with the icon in the hue (Now the accent, Reminders amber, Watching sky, Inbox teal, More neutral), and More's rows lead with a 10dp dot in their kind's hue (Shopping amber, Money and Calls sage, Projects sky, People and About you plum).
- **Type** (`Type.kt`): Roboto Flex as a Google Fonts downloadable font (`DanaSans`; Play services provider, certificates in `res/values/font_certs.xml`), the system sans as the fallback. Display 34–40 for screen titles (`display*`), title 22 (`titleLarge`, `headlineSmall`), row titles 16 (`titleMedium`), body 16 (`bodyLarge`), supporting 14 (`bodyMedium`), 12 only for axis and time labels (`bodySmall`, `label*`). Times use tabular figures (`TextStyle.tabular()`; `labelMedium/Small` have them). No serif and no mono in the styles: `DmMono` is for code only, `DanaSerif` only for the assistant sheet's "d" mark, the TV clock and the kiosk pairing title. `MetaLabel(text)` is the one-line metadata label (sentence case, never tiny uppercase). `PlaceTitle` (`PlaceHeader`'s title): displaySmall's 34sp in SemiBold with −0.75sp tracking, a little more voice than the other display styles.
- **Shape** (`Shape.kt`): 8/12/16/24/28dp; groups 24dp outer, 8dp inner, 2dp between joined rows (`Group`).
- **Spacing**: `Space.*`, 16dp margins, an 8dp rhythm. Every row aligns to the same columns: leading node or icon, content, trailing time / state / action.

## Circuit components (`ui/components/circuit/`)
Node shapes mean the same everywhere: Circle = source or moment, Slot = rule, Diamond = AI check, RoundedSquare = action or done.
- `CircuitNode(shape, state, size, icon, strokeColor?, glyphColor?)` — states Idle, Passed, Dropped, Firing, Waiting (warm, breathing), Done (tonal), Paused (dashed); the two colours override the state's (Now's warm ring for a needs-you row, the accent ring of a live one). `NodeSize.Small` (circuits in lists) / `Large` (one watch) / `Leading` (32dp row lead).
- `NodeLine(nodes, positions?, orientation)` — a horizontal or vertical line of `LineNode`s with labels; segments follow the states (solid accent through passed nodes, warm into a waiting node, dashed after the current one or when paused) or `SegmentStyle` overrides; `pulseSegment` travels a pulse along one. A horizontal label takes room only up to its labelled neighbours (an unlabelled node next to it gives its room away).
- `CircuitRow(title, source, rule, ai?, action, time, state)` + `CircuitColumnHeader()` — a watch's line on the shared columns (`CircuitColumns`: When · Rule · AI check · Then · last fired).
- `StepLine(steps)` / `StepLineMini(done, total)` — a run's steps, the current one spinning, a pulse travelling into it.
- `TimelineRow(time, node, title, subtitle)` — time | node | content rows of a vertical timeline, the line joining row to row; the node sits on the title's first line by an offset (never negative padding).
- `GroupedSection(title, meta, rows)`, `GroupRow(shape, leading, title, subtitle, trailing)`, `groupItemShape(index, count)` — tonal groups with joined rows. `SectionHeader(title, meta, titleColor)`: the title keeps its room, a long meta shortens (Late is warm).
- `AskDanaButton(onClick)` — the tonal mic (48dp, 16dp corners) in the top-right header slot; `ConversationButton(onClick)` — 48dp chat glyph beside it that opens the thread. `HeaderSlot` (top 8dp, row 48dp, margin 16dp, gap 8dp) is where they sit. `PlaceHeader(title, supporting, trailing)` — a place's title on a ≥ 48dp row with its header buttons at its end, so they scroll with it and line up on the 16dp margin (Now uses it; places that still use the floating ask get the same position).
- Conversation cards (`ui/screens/chat/ToolCards.kt`, from `data/chat/ThreadItems.kt`'s `ThreadItem.of(rows)`; the thread, the power-button sheet, kiosk / TV): `ToolRunCard(item, reply)` — a turn's tool calls on a `surfaceContainerLow` card (20dp corners, ≤ 560dp): one step = `StepLineMini` + its words in inkSoft (warm when it failed), several = a `StepLine` of the last four; Dana's reply under them inside the card (`ChatBubble(bare = true)`), else a short plain result; a "Details" text action opens the calls' arguments and answers in mono. `ApprovalCard(entry, onAnswer)` — a call that asks first on `warmSurface`: a warm icon square, the title ("Send a WhatsApp message to Noa?"), one line why it asks, the words it would send on `warmSurfaceHigh`, label · value details, then the filled yes (Send / Delete / Go ahead) and the warm text no (Don't send / Keep it / Don't). Bubbles: yours violet (`userBubbleColor()`, #3A2F55 dark / #E2D8FA light, 20dp with a 6dp tail corner, at the end, ≤ 300dp); Dana's on a tonal card at the start. `MemoryLine`: wire hairlines either side of an accent node and accent label. Quiet separators: centred mute text.
- Ask bar (`ui/shell/AskBar.kt`, only under the thread): a 56dp tonal pill (radius 28) with + and "Message Dana", then `TalkButton`: an accentFilled pill "Hold to talk" (round in FULL), Send with text, Stop while busy.
- Motion only where something is live (pulse, breath, spinner), all off under `reducedMotion()` (animator scale 0, or TV / kiosk).

## Motion (`ui/theme/Motion.kt`, `ui/components/Life.kt`)
- **Tokens**: `Motion.FAST` 120 / `BASE` 200 / `SLOW` 320 ms; easings `Standard` (.2,0,0,1), `Decelerate` (.05,.7,.1,1) for arriving, `Accelerate` (.3,0,.8,.15) for leaving; `Rise` 8dp, `Slide` 12dp; `COMPLETE` 420, `FLASH` 600, `FOCUS` 150 ms at `FOCUS_SCALE` 1.05; `PRESS_SCALE` 0.96; `POP_SCALE` 1.15; `CELEBRATE` 700 ms. Springs: `Motion.bouncy()` (damping .5, stiffness 520: a visible ~15% overshoot, ~350 ms — popping in, a release, a picked icon) and `Motion.settle()` (damping .7, stiffness 380: passes its target by ~5% and settles, ~400 ms — a place sliding in).
- **Only** graphicsLayer alpha / translation / scale or a draw animate, from a Modifier.Node or a value read inside a draw / layer lambda, so a frame never recomposes a screen. No blur, no animated shadow, no animated size or layout (except collapsing the one completed reminder). Nothing loops except an indicator while its state is on (listening ring, typing dots, the dial); delight moments play once and never loop; `motionOff()` (animator duration scale 0) turns those off, and Compose's own animations jump to their end.
- **Patterns**: press = `PressIndication` (the app's `LocalIndication`: the ripple's tint + a draw-phase squish to 0.96, at most ~8dp a side, springing back on release with `bouncy()` so it passes rest by a hair); rows arriving = `Modifier.arrive(screen, index)` (fade + 8dp rise, 30ms apart, first 8 rows, once per screen per process — never on refresh); a place / drill-down switch = `Modifier.enterOnChange(key, direction)` (fade + 12dp from the side of travel on `settle()`); a new chat message = `riseIn(play)` with `TailArrivals` (only rows appended at the end, not the first load or older pages); a value that changed = `flashOnChange(key, tint)`; a number = `RollingText`; loading = `Modifier.skeleton()` (one shimmer sweep, then still); listening = `pulseRing(active, accent)`; the canvas is plain (no glow). A row tile of a `GroupedSection` takes a modifier outside its clip (`item(key, color, modifier)`), so `arrive` moves the tile with its content (More's rows, Watching's lines). A numeric `SectionHeader` meta rolls (`RollingText`).
- **Delight** (`ui/components/Delight.kt`; each a Modifier.Node animating a layer's scale or a draw, played once, off without rich motion or with animations off): `popIn(play)` (from 40%, faded, to full size on `bouncy()`); `popOnRise(value, popOnAttach)` (swells to `POP_SCALE` in 90 ms and springs back when `value` rises; going down never pops; `popOnAttach` pops from 0 as it first appears) — the nav's picked icon (`popOnRise(if (selected) 1 else 0)`) and the Inbox badge (pops when its count rises or the badge shows up while the nav is on screen; the count rolls); `growIn(play)` (scaleX 0 → 1 from the start, mirrored in RTL) — `HueMark`, so an empty state's mark grows in while `QuietEmptyState` rises in (`riseIn`); `celebrate(play, colors, reach)` — 8 tiny dots in `celebrationHues()` (the named hues and the accent, never warm) leave the element's edge, fly out ≤ 26dp and fade over `CELEBRATE`, drawn over it, then nothing; `Celebrations.claim(key)` (true once per key per process). Now's calm card plays it on its check node (with `popIn`) when calm has just come (the last needs-you row went while Now was open) or for the day's first calm in the process; scrolling it back doesn't replay it. Circuit's live loops (a line's pulse, a waiting node's breath, a step's spinner) are off under `reducedMotion()`.
- **Flavours**: `LocalRichMotion` (set by `DanaTheme`) is true on the phone only. The TV and the wall tablet get press, focus and state changes: `arrive`, `enterOnChange`, `riseIn`, the shimmer and the glow are off there, and the assistant sheet switches without its slide / fade.

## Adaptive layout (`ui/adaptive/Adaptive.kt`) — Galaxy Z Fold target
Real windows (360 dpi): cover ≈ 555×876 dp, inner ≈ 1088×821 dp (821×1088 rotated). Check every new screen at all three (emulator: `wm size 1248x1972` / `2448x1848` / `1848x2448` + `wm density 360`). Use three panes only with ≥ ~900 dp of content width; split a detail pane into story | tinted aside from ~600 dp of pane width (People).
`windowTier()` from live width: COMPACT <600 (cover screen/phone: bottom bar, single pane) · MEDIUM 600–839 (unfolded portrait: rail + list + content) · EXPANDED ≥840 (unfolded landscape/tablet: rail + list + content + context pane). Use `PaneRow` / `Pane(width=…)` with `PaneWidth.list/listNarrow/context`. The activity handles fold/size configChanges itself, so **state must survive a fold/unfold** (hoist in ViewModel / `rememberSaveable`, don't rely on recreation). Never assume a fixed width; panes must degrade gracefully tier by tier.

Per-screen pane plan (EXPANDED → MEDIUM → COMPACT):
- **Reminders** (main-screen shell): list (tinted) | editor | thread, or the board across, under the day view → list | editor (or the board), thread as a sheet → the compact day view over the list → editor drill-down.
- **Memory**: Categories | Memory list | Memory detail → list | detail → list.
- **Projects** (a wide place): side list (projects, the open project's sections) | project or section page (two columns; the compare table across the width, option names fixed) | entry pane beside it from a 760dp stage, else over it → one level at a time on the cover (projects → project → section → entry), Back pops a level.
- **Money** (a wide place, under More): side pane (header, month, banners, views) | the view (two columns from 600dp) | transaction / saving pane beside it from a 760dp stage → cover: header, views strip, one column, the item full screen.
- Hebrew titles and names take their own width (not a full-width box) so they stay at their start beside a number, like the web's `<bdi dir="auto">`; `MetaLabel` is one line, so anything that can run long gets wrapping text.
- **Calls**: Call list | Call detail (summary, transcript) | Actions/people/tasks extracted → list | detail → drill-down.
- **People**: People list | person (summary + history) | At a glance (facts, reminders, notes) → list | person (one column) → drill-down.
- **Weekly review**: summary + section jumps + Apply (side) | items → one column with a sticky Apply bar.

## Power-button assistant (`DanaVoiceInteractionSession`, `FloatingAssistantOverlay`)
Quick, glanceable, one-handed: a bottom sheet anchored to the thumb zone over the current app, not a full chat window. Large live transcript, one primary voice control, compact result cards, easy dismissal, works on cover screen and unfolded inner screen (560dp, centred).
The sheet slides up and fades in while the scrim fades (state changes only on TV / kiosk: no slide); turns that arrive while it is open rise in; listening draws a pulse ring leaving the dial's button (the ask bar's mic too), gone when listening stops.
It is the shared thread (device `phone`), never a new session: the same `UndoRows` as the thread under replies, the thread's cards (`ToolRunCard` for a turn's steps, the warm `ApprovalCard` for a call that asks first, violet bubbles and Dana's tonal cards), "Dana · learned phrase" on shortcut replies, and a BARE "Open the thread in Dana →" after the first turn. It scrolls to its end when a turn finishes.
**Screen** (`ui/components/assistant/ScreenControl.kt`, phone only): a 44dp chip left of the input, in thumb reach and tappable while listening. It is off every time the sheet opens: hairline outline with a `CropFree` icon. On, it is filled vermilion with a check. It must never be ambiguous. When it is on, a status line sits above the dock: a 3dp accent bar, a 56dp-high thumbnail, the MetaLabel "Screen goes with this message", "App · host or title", one line for anything missing ("Text only · screenshots are off in settings" with a BARE Settings button, "Text only · this app blocks screenshots", "Screenshot only · no text from this app") and a × to leave it out. When it is unavailable, the chip is muted and reads "Screen off" or "No screen". A tap explains why in one line: "Screen sharing is off in the assistant settings." with a PRIMARY "Turn on" (opens the system assistant switches), or "This app doesn't let assistants see its screen." The chip is hidden when the sheet was opened from Dana itself (widget, Dana in front) and on kiosk/TV. Sent messages carry a MetaLabel caption "Screen · App" in the accent colour, plus "· text only" when no image went. The approval card reads "Asking because the screen was shared." when the server asks because of it.


## Pane spec (all multi-pane screens — keep columns identical across tabs)
`[ global header (ScreenTopBar: kicker + serif title + actions) ]` over `[ SIDE 280dp tinted | MAIN flex | (MAIN flex) | ASIDE 288dp tinted ]`.
Widths via `sidePaneWidth()` / `asidePaneWidth()` (248/256dp under 960dp wide). Panes have no headers of their own (use a `MetaLabel` row). Only SIDE and ASIDE are tinted; the main/detail panes never are. The nav rail appears from 720dp; below that a bottom bar. 960dp+ is the Fold unfolded landscape: SIDE + MAIN + ASIDE.

## Main screen shell (`ui/shell/`, phone; spec: `docs/design/dana-mock.html`)
Tiers come from window width, independent of `windowTier()`: **STACKED** < 600 dp (cover) · **SPLIT** 600–899 (unfolded portrait) · **FULL** ≥ 900 (unfolded landscape).

- FULL: `[ list SIDE (tinted) | stage + thread ]`; nav at the bottom of the list column, ask bar at the bottom of the thread column. A place with no stage spans list + stage and gets a title cell top-left.
- SPLIT: list (tinted) | stage, thread as a sheet with the ask bar at its bottom.
- STACKED: one column (list, or the stage when something is picked), thread as a sheet over it with the ask bar at its bottom (the bottom bar of the places hides while it is open and while the keyboard is up). Warm only for needs you; motion only on live things (the waiting node's breath).

While dragging, the track takes a soft accent wash, the half hour under the finger is a dashed accent line with the time in an accentFilled bubble, and the targets get a dashed accent outline (filled tonal and grown 6% when hovered).
- People, callers and widgets: initials on `hues.forName(id)` (tint + hue text) everywhere: People, the caller card (Views: `DanaHues` directly), the People widget.

## TV and kiosk (native parts)
- **TV** (`src/tv`, D-pad): focus is the motion. `FocusTile` scales 1.0 → 1.05 in 150ms (`Motion.FOCUS`, read in its layer) and takes a 2dp accent outline; nothing else moves except the camera picture-in-picture fading in (`Motion.BASE`, decelerating). Home Assistant tiles carry their domain's hue (lights amber, climate / sensors sky, switches / fans / scenes teal, covers sage, locks / alarms rose, media plum): a 3dp start bar always, an opaque tint (`compositeOver`, no alpha layer) and the state in the hue when on. The TCL TV is slow and 32-bit: no per-frame recomposition, no alpha layers on large surfaces.
- **Kiosk** (`src/kiosk`): the settings dialog uses the hues for its meters (wake score amber, sage once it would fire; mic level teal) and section dots; the assistant sheet is the phone's, without its slide / fade. Its dashboard is the web page.
- **Widgets** (Glance, phone): colour only — the app's tokens, event times in sky, overdue in rose, drifting in amber, people's initials on their hue.


## Watch (`:wear`)
Dark values only, on a true-black canvas. The idle main screen is the website's "06:52": the greeting in DM Mono caps (10sp, .16em, `DanaWear.EmberText`), the user's first name in Instrument Serif (32sp), then up to three 13sp dot lines (7dp dots: events sky, the Inbox teal, tasks amber, overdue ember) (`TodayBlock`). The hues live in `DanaWear` (`ui/theme/WearTheme.kt`), with `tint()` at 14%. Reminder groups take `groupHue(name)` (a stable hash: the watch is not sent a group's stored colour; ungrouped is amber): a dot and mono label in the hue, a tinted row and a ring in the hue. Overdue and "needs you" are ember, Done and ticks sage, Snooze amber, errors rose. Tiles use the same values (`tiles/TileConstants.kt`). Motion is Wear's press ripple and state changes, with `DanaMotion`'s tokens:
- **Done on a reminder**: the ring fills and the check scales in, the strike-through grows, then the row fades and folds (~380 ms); then the phone is told.
- **Shopping tick**: the ring fills sage.
- **Listening**: an ember ring grows from the mic and fades. It exists only while listening and is skipped when animations are off (`DanaMotion.enabled()`).

Animations change drawing only, never the list's structure, except the one row that folds. No arrival animations; nothing loops when idle. The app has no ambient mode (the system shows the watch face).
