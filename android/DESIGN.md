# Dana Design System v2 — "Ink & Paper"

A personal chief-of-staff, not a chatbot. The UI reads like a well-set notebook: serif headlines, mono metadata, hairline rules, one vermilion accent. **Avoid generic-AI tropes**: no purple/blue gradients, no glowing orbs, no "How can I help?" hero, no icon-in-circle empty states, no card-per-row lists.

## Tokens (`ui/theme/`)
- **Palette**: Dark "Ink" canvas `#13100E`; Light "Paper" canvas `#F3EDE1`. One accent: ember / vermilion (`#FF6A3D` dark / `#D1401A` light) for primary actions, selection, focus, "needs you" and approvals. Never hardcode colours in screens — use `MaterialTheme.colorScheme.*`, the tokens in `Color.kt` or `hues`.
- **Hues** (`Hue`, shared with the web app and the watch — change them everywhere or nowhere), dark / light: ember `#FF6A3D`/`#D1401A` (the accent) · amber `#F2A93B`/`#A86A00` reminders, tasks, warnings · sage `#5FBF8A`/`#2E7D52` calls, done, money in · teal `#3DBFB3`/`#1F7A72` messages, notifications · sky `#5AA7F0`/`#2F6FB5` calendar, info · plum `#B892F2`/`#7044B8` people, memory · rose `#F0709A`/`#B83A64` alerts, errors, money out. Read them through `hues` (the theme's `DanaHues`): `hues.of(Hue.SKY)`, `hues.tint(c)` (14% dark / 12% light — fills, tiles, pills), full hue for bars, dots and icons, `hues.text(c)` for text (on Paper darkened 30% towards ink to keep 4.5:1 on its own tint), `hues.forName(name)` for a stable hue per person / app, `hues.fromHex(stored)` for a list's or project's stored colour (a hue comes back in the theme's value). `Success/Warning/Info/Danger` are the status names over sage/amber/sky/rose; `CategoryHues` is the picker order for user colours (stored as the dark value). Money charts (`MoneyPalette`) use the hues' dark values as fills; amounts as text go through `goodColor()` / `badColor()`.
- **Type**: `headline*`/`display*` = Instrument Serif (editorial titles, big dates, empty-state statements; Latin only). Body/title = Inter. `labelSmall/labelMedium` = DM Mono — use `MonoLabel(text)` (uppercases) for counts, times, kickers, ids. Chat/user content stays Inter (Hebrew/RTL support!).
- **Shape**: 6/10/14/18/28dp. Prefer hairline-ruled rows (`Rule()`) over boxed cards; use `GlassCard` only for genuinely grouped content (forms, settings).
- **Spacing**: `Space.*` (4dp scale), 16dp gutters.

## Motion (`ui/theme/Motion.kt`, `ui/components/Life.kt`) — "Ember"
- **Tokens**: `Motion.FAST` 120 / `BASE` 200 / `SLOW` 320 ms; easings `Standard` (.2,0,0,1), `Decelerate` (.05,.7,.1,1) for arriving, `Accelerate` (.3,0,.8,.15) for leaving; `Rise` 8dp, `Slide` 12dp; `COMPLETE` 420, `FLASH` 600, `FOCUS` 150 ms at `FOCUS_SCALE` 1.05.
- **Only** graphicsLayer alpha / translation / scale or a draw animate, from a Modifier.Node or a value read inside a draw / layer lambda, so a frame never recomposes a screen. No blur, no animated shadow, no animated size or layout (except collapsing the one completed reminder). Nothing loops except an indicator while its state is on (listening ring, typing dots, the dial); `motionOff()` (animator duration scale 0) turns those off, and Compose's own animations jump to their end.
- **Patterns**: press = `PressIndication` (the app's `LocalIndication`: the ripple's tint + a draw-phase shrink to 0.97, at most ~8dp a side); rows arriving = `Modifier.arrive(screen, index)` (fade + 8dp rise, 30ms apart, first 8 rows, once per screen per process — never on refresh); a place / drill-down switch = `Modifier.enterOnChange(key, direction)` (fade + 12dp from the side of travel); a new chat message = `riseIn(play)` with `TailArrivals` (only rows appended at the end, not the first load or older pages); a value that changed = `flashOnChange(key, tint)`; a number = `RollingText`; loading = `Modifier.skeleton()` (one shimmer sweep, then still); listening = `pulseRing(active, accent)`; the main canvas = `emberGlow` (static radial accent at ~7%, top-left, rendered once into an offscreen layer and only composited after that — evaluating the gradient every frame cost whole frames on a weak GPU).
- **Flavours**: `LocalRichMotion` (set by `DanaTheme`) is true on the phone only. The TV and the wall tablet get press, focus and state changes: `arrive`, `enterOnChange`, `riseIn`, the shimmer and the glow are off there, and the assistant sheet switches without its slide / fade.

## Adaptive layout (`ui/adaptive/Adaptive.kt`) — Galaxy Z Fold target
Real windows (360 dpi): cover ≈ 555×876 dp, inner ≈ 1088×821 dp (821×1088 rotated). Check every new screen at all three (emulator: `wm size 1248x1972` / `2448x1848` / `1848x2448` + `wm density 360`). Use three panes only with ≥ ~900 dp of content width; split a detail pane into story | tinted aside from ~600 dp of pane width (People).
`windowTier()` from live width: COMPACT <600 (cover screen/phone: bottom bar, single pane) · MEDIUM 600–839 (unfolded portrait: rail + list + content) · EXPANDED ≥840 (unfolded landscape/tablet: rail + list + content + context pane). Use `PaneRow` / `Pane(width=…)` with `PaneWidth.list/listNarrow/context`. The activity handles fold/size configChanges itself, so **state must survive a fold/unfold** (hoist in ViewModel / `rememberSaveable`, don't rely on recreation). Never assume a fixed width; panes must degrade gracefully tier by tier.

Per-screen pane plan (EXPANDED → MEDIUM → COMPACT):
- **Reminders** (main-screen shell): list (tinted) | editor | thread, under the day strip → list | editor, thread as a sheet → list → editor drill-down.
- **Memory**: Categories | Memory list | Memory detail → list | detail → list.
- **Projects** (a wide place): side list (projects, the open project's sections) | project or section page (two columns; the compare table across the width, option names fixed) | entry pane beside it from a 760dp stage, else over it → one level at a time on the cover (projects → project → section → entry), Back pops a level.
- **Money** (a wide place, under More): side pane (header, month, banners, views) | the view (two columns from 600dp) | transaction / saving pane beside it from a 760dp stage → cover: header, views strip, one column, the item full screen.
- Hebrew titles and names take their own width (not a full-width box) so they stay at their start beside a number, like the web's `<bdi dir="auto">`; `MonoLabel` is one line, so anything that can run long gets wrapping text.
- **Calls**: Call list | Call detail (summary, transcript) | Actions/people/tasks extracted → list | detail → drill-down.
- **People**: People list | person (summary + history) | At a glance (facts, reminders, notes) → list | person (one column) → drill-down.
- **Weekly review**: summary + section jumps + Apply (side) | items → one column with a sticky Apply bar.

## Components (`ui/components/DesignSystem.kt`)
`ScreenTopBar(title, kicker=…)` (serif title, mono kicker), `ScreenTopBarSlots`, `MonoLabel`, `Rule`, `SectionLabel` (with a dot in its group's hue), `StatusPill` (the hue's tint, a dot, text in the hue), `HueInitials` (initials on a hue from the name), `HueMark` (the one 18×3dp hue bar an empty state may carry), `GlassCard`, `InkChoice` (outlined 10dp choice chip; accent outline + accent tint when selected, `solid` = the ember gradient), `InkButton` (SOLID = `emberGradient()`, accent warming towards the end, mirrored in RTL). Empty states: `QuietEmptyState` (`screens/common`: hue mark, italic serif line, muted line; never an icon in a circle). Motion helpers: see Motion above. Navigation: Material 3 `NavigationBar` (compact) / `NavigationRail` (≥600dp).

## Power-button assistant (`DanaVoiceInteractionSession`, `FloatingAssistantOverlay`)
Quick, glanceable, one-handed: a bottom sheet anchored to the thumb zone over the current app, not a full chat window. Large live transcript, one primary voice control, compact result cards, easy dismissal, works on cover screen and unfolded inner screen (560dp, centred).
The sheet slides up and fades in while the scrim fades (state changes only on TV / kiosk: no slide); turns that arrive while it is open rise in; listening draws a pulse ring leaving the dial's button (the ask bar's mic too), gone when listening stops.
It is the shared thread (device `phone`), never a new session: the same `UndoRows` as the thread under replies, the "Dana asks first" card only for tools that still ask, "Dana · learned phrase" on shortcut replies, and a BARE "Open the thread in Dana →" after the first turn. It scrolls to its end when a turn finishes.
**Screen** (`ui/components/assistant/ScreenControl.kt`, phone only): a 44dp chip left of the input, in thumb reach and tappable while listening. It is off every time the sheet opens: hairline outline with a `CropFree` icon. On, it is filled vermilion with a check. It must never be ambiguous. When it is on, a status line sits above the dock: a 3dp accent bar, a 56dp-high thumbnail, the MonoLabel "Screen goes with this message", "App · host or title", one line for anything missing ("Text only · screenshots are off in settings" with a BARE Settings button, "Text only · this app blocks screenshots", "Screenshot only · no text from this app") and a × to leave it out. When it is unavailable, the chip is muted and reads "Screen off" or "No screen". A tap explains why in one line: "Screen sharing is off in the assistant settings." with a PRIMARY "Turn on" (opens the system assistant switches), or "This app doesn't let assistants see its screen." The chip is hidden when the sheet was opened from Dana itself (widget, Dana in front) and on kiosk/TV. Sent messages carry a MonoLabel caption "Screen · App" in the accent colour, plus "· text only" when no image went. The approval card reads "Asking because the screen was shared." when the server asks because of it.


## Pane spec (all multi-pane screens — keep columns identical across tabs)
`[ global header (ScreenTopBar: kicker + serif title + actions) ]` over `[ SIDE 280dp tinted | MAIN flex | (MAIN flex) | ASIDE 288dp tinted ]`.
Widths via `sidePaneWidth()` / `asidePaneWidth()` (248/256dp under 960dp wide). Panes have no headers of their own (use a `MonoLabel` row). Only SIDE and ASIDE are tinted; the main/detail panes never are. The nav rail appears from 720dp; below that a bottom bar. 960dp+ is the Fold unfolded landscape: SIDE + MAIN + ASIDE.

## Main screen shell (`ui/shell/`, phone; spec: `docs/design/dana-mock.html`)
Tiers come from window width, independent of `windowTier()`: **STACKED** < 600 dp (cover) · **SPLIT** 600–899 (unfolded portrait) · **FULL** ≥ 900 (unfolded landscape).
- FULL: `[ list SIDE (tinted) | day strip across stage + thread ]` over `[ list | stage | thread ASIDE (tinted) ]`; nav at the bottom of the list column, ask bar at the bottom of the thread column. A place with no stage spans list + stage and gets a title cell top-left.
- SPLIT: day strip on top, list (tinted) | stage, thread as a sheet, ask bar + nav at the bottom.
- STACKED: one column (list, or the stage when something is picked), thread as a sheet over it, a one-line thread peek + ask bar, then a slim row of the four places (hidden while the keyboard is up).
- Canvas: the faint static `emberGlow` at the top (phone only). Switching place fades the new one in with a 12dp slide from the side of travel; drilling in on the cover slides from the end, Back from the start; the thread sheet slides up and fades (decelerating), leaves faster.
- Nav: mono uppercase labels, a 2dp accent line above the current place that grows from its middle over a faint accent wash, counts in accent (they roll when they change). No icons.
- Rows: hairline-ruled; selected = canvas background + 3dp accent bar at the start. Titles decide direction per line (Hebrew right-aligned).
- Now rows (`ui/screens/now/`): a 30dp leading tile (`NowTile`, same rounded square as the Notifications app tiles; 38dp on the stage, 24dp on quieter suggestions) says where the item came from: the app's real icon for anything from a notification, else an outline glyph for the kind, on its kind's hue (`NowGlyph.hue()`: approval ember, alert rose, call and money sage, calendar sky, reminder and Dana's checks amber, review plum, notifications and suggestions teal; the tint behind, the glyph in the hue). Then the mono source kicker in the kind's hue, semibold title, muted why; rows arrive staggered on the first load and are transparent at rest (the glow shows through), canvas only while swiping (buttons align under the text, the open evidence panel stays full width); cover rows expand in place and swipe (right = primary, left = dismiss, the revealed side says which). Unfolded the stage holds evidence then a "Decide" rule with the choices/checks and a SOLID primary. Check rows lay out in their label's own direction. Empty Now = italic serif "Nothing needs you." + one muted line, no illustration.
- Notifications: a filled noise box tinted teal while there is noise, sage once calm, glowing briefly when the count changes (SOLID "Clear the noise · N"), a teal-outlined "Dana noticed" box, app rows with a 30dp icon tile (2-letter fallback on a hue from the app's name), mono flags in accent ("INTERRUPTS" in rose), summary points per line by script; the app page uses `InkChoices` for the three-way rule.
- Search (`SearchPane`): mono group labels over hairline rows; the last row "Ask Dana: “…”" in accent with ↵.
- Reminders (`ReminderRow`): a 3dp start bar in the list's stored colour (`hues.fromHex`, amber without one), the list as a tinted mono chip after the "when" line (By when) or a dot on the section head (By list); done = the circle filled with that hue and checked. Completing plays one ~420ms animation (the circle fills and its check draws, the strike-through grows along the title's lines in reading order, then the row fades and collapses), the reminder kept in place until it ends; Undo (or un-checking) brings it back the same way, reversed.
- Thread (`ThreadPane`): new messages at the end rise 8dp and fade in; Dana's typing dots are ember; quiet separators (mono "13:10 · watch" between hairlines) where a new conversation started, "Loading earlier…" at the top, "Nothing said yet." when empty. Under a reply: `InkChoice` "Undo" + the label; afterwards a plain line "Undone." / "Too late to undo that." (muted detail), never a red error. Learned-phrase replies get a mono "learned phrase · no model" caption. Tools that ask: a "Asks first" chip, "Dana asks first", Cancel / Go ahead.
- On screen: unfolded, a mono "On screen · title" line with an accent start bar and a 40dp × above the ask field; on the cover the same line is pinned at the top of the thread sheet.
- About you (More): one centred column (≤ 680dp), facts as editable lines saved on blur/Done with a muted source caption, × to forget, "N of M characters", learned phrases, self-check rows with a status dot. Every change offers Undo.
- Caller card (plain Views over the dialer): the same tokens, Ink or Paper from the theme setting; body lines start on their own script's side; 560dp centred when unfolded.
- Day strip: an 84dp Now cell (accent "NOW", italic serif time), hour cells that fit the width (2–8), At home, On waking; events on a sky chip with a sky start bar, reminders in muted text after an amber dot; the hovered cell takes the accent tint while dragging.
- People, callers and widgets: initials on `hues.forName(id)` (tint + hue text) everywhere: People, the caller card (Views: `DanaHues` directly), the People widget.

## TV and kiosk (native parts)
- **TV** (`src/tv`, D-pad): focus is the motion. `FocusTile` scales 1.0 → 1.05 in 150ms (`Motion.FOCUS`, read in its layer) and takes a 2dp accent outline; nothing else moves except the camera picture-in-picture fading in (`Motion.BASE`, decelerating). Home Assistant tiles carry their domain's hue (lights amber, climate / sensors sky, switches / fans / scenes teal, covers sage, locks / alarms rose, media plum): a 3dp start bar always, an opaque tint (`compositeOver`, no alpha layer) and the state in the hue when on. The TCL TV is slow and 32-bit: no per-frame recomposition, no alpha layers on large surfaces.
- **Kiosk** (`src/kiosk`): the settings dialog uses the hues for its meters (wake score amber, sage once it would fire; mic level teal) and section dots; the assistant sheet is the phone's, without its slide / fade. Its dashboard is the web page.
- **Widgets** (Glance, phone): colour only — the app's tokens, event times in sky, overdue in rose, drifting in amber, people's initials on their hue.


## Watch (`:wear`)
Dark values only, on a true-black canvas. The hues live in `DanaWear` (`ui/theme/WearTheme.kt`), with `tint()` at 14%. Reminder groups take `groupHue(name)` (a stable hash: the watch is not sent a group's stored colour; ungrouped is amber): a dot and mono label in the hue, a tinted row and a ring in the hue. Overdue and "needs you" are ember, Done and ticks sage, Snooze amber, errors rose. Tiles use the same values (`tiles/TileConstants.kt`). Motion is Wear's press ripple and state changes, with `DanaMotion`'s tokens:
- **Done on a reminder**: the ring fills and the check scales in, the strike-through grows, then the row fades and folds (~380 ms); then the phone is told.
- **Shopping tick**: the ring fills sage.
- **Listening**: an ember ring grows from the mic and fades. It exists only while listening and is skipped when animations are off (`DanaMotion.enabled()`).

Animations change drawing only, never the list's structure, except the one row that folds. No arrival animations; nothing loops when idle. The app has no ambient mode (the system shows the watch face).
