# Build a Dana add-on

Follow the guide `website/build-an-addon.md` in this repository, from its first section to its last:
read it fully before doing anything, then interview the person (one question at a time), propose the
design and wait for a yes, build in the loop it describes, install the add-on on their Dana and try it
with them. Outside a Dana checkout, read the same guide at
https://ronganam.github.io/dana/build-an-addon.md.

The guide is the single source: when this file and the guide differ, the guide wins.
