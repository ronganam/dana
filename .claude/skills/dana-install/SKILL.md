# Install Dana

Follow the guide `website/install.md` in this repository, from its first section to its last: read it
fully before doing anything, keep its rules (never print the person's keys, never expose the server
without authentication, confirm before anything destructive, stop and ask when a step fails), ask its
questions one at a time, then do the steps with the person. Outside a Dana checkout, read the same
guide at https://ronganam.github.io/dana/install.md.

The guide is the single source: when this file and the guide differ, the guide wins.
