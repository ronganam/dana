# Your site addons

Each folder here with an `addon.py` is loaded as an addon after the official ones: by the server when you run it from this checkout, and by `server/bin/deploy` into your image. Start from the working example in `examples/addons/hello/` (`cp -r ../../examples/addons/hello my_addon`). The guide is `server/docs/writing-an-addon.md`.
